# WellTrackeR: Personal Health Tracker with AI Recommendations

WellTrackeR is an AI-powered web-based health monitoring system designed for continuous health tracking, personalized recommendations, and seamless collaboration between doctors and patients.

---

## 📌 Project Overview & Motivation

Modern busy lifestyles often result in inadequate continuous health monitoring, contributing to lifestyle-related diseases such as **diabetes, heart disease, and hypertension**.

- **The Problem:** Limited preventive care and gaps in effective patient-doctor communication.  
- **The Solution:** A digital platform for daily tracking of health metrics with **AI-driven personalized recommendations**.

---

## 🛠️ System Architecture & Technology Stack

WellTrackeR is built on a **Three-Tier Architecture**:

### Frontend Layer
- **Languages:** HTML5, CSS3, JavaScript  
- **Data Visualization:** Chart.js for interactive trend analysis

### Backend Layer
- **Server Logic:** PHP  
- **AI Integration:** Python with Flask  
- **Reporting:** DOMPDF for report generation  
- **Communication:** SMTP for email notifications

### Database Layer
- **System:** MySQL  
- **Design:** Relational schema with 10 core tables

### AI/ML Components
- **Tools:** NumPy, Pandas, Scikit-learn, Joblib  
- **Datasets:** Diabetes, Lung Cancer, Brain Tumor images  
- **Interactive Support:** Chatbot integration via Dialogflow

---

## 🚀 Key Features & Modules

WellTrackeR consists of **seven core modules**: User Management, AI Recommendation, Visualization, and more.

### For Patients
- Daily vitals logging (**BP, sugar, heart rate, weight**)  
- AI-generated health risk predictions

### For Doctors
- Secure dashboards for **medical notes**  
- Patient progress monitoring

### For Administrators
- User account management  
- Feedback and community post moderation
